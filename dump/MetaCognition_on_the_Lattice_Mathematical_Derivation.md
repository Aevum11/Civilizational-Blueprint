## 4. The T→D_T Self-Loop as a Lattice Trajectory

### 4.1 Trajectory structure

T_S's traversal is a finite sequence of binding events indexed by time:

$$\pi_{T_S}(\tau) = (w_0, w_1, w_2, \ldots, w_n), \quad w_i = T_S(\text{input}_i)$$

$$D_{T_S}(\tau_n) = \{w_0, w_1, \ldots, w_n\} \text{ (as a set, with multiplicity-1 for each distinct lattice point visited)}$$

The **traversal** preserves order and multiplicity; the **binding record** is just the set.

### 4.2 Partition of traversal events

Each binding event $w_i$ is classified as:

- **External**: $w_i \notin \{w_0, \ldots, w_{i-1}\}$ — a new lattice position, not previously visited
- **Self-referential**: $w_i \in \{w_0, \ldots, w_{i-1}\}$ — a revisit of a previously-bound point

This gives the RMSAE partition $N = N_\text{ext} + N_\text{self}$ as a direct geometric count:

$$N_\text{self}(\tau) = |\{i \leq n : w_i \in \{w_0, \ldots, w_{i-1}\}\}|$$
$$N_\text{ext}(\tau) = n + 1 - N_\text{self}(\tau)$$

**$\rho$ from RMSAE is literally the fraction of lattice revisits in the traversal:**

$$\rho = \frac{N_\text{self}}{N_\text{self} + N_\text{ext} + \varepsilon}$$

This is now a geometric quantity — the *revisit density* of T_S's trajectory through Sempaevum.

### 4.3 Why the self-loop MATTERS structurally

A normal traversal (ρ = 0) leaves $D_{T_S}$ growing but never revisited. T_S binds new positions; the prior bindings sit in memory unused.

A self-referential traversal (ρ > 0) revisits bound positions. Each revisit is an opportunity to:
- Verify the binding (is w_i still correctly bound?)
- Detect a gap near w_i (are there nearby unbound positions T_S should bind?)

- Discover a shadow (detect that w_i's true structural identity requires a higher LCM viewing)

The self-loop is the geometric substrate for all these operations. Without revisits, there is no self-knowledge.

### 4.4 Closed loops vs open walks

A traversal can include:
