## 7. Proof of Palindromic Symmetry

### 7.1 Statement

**Theorem D.3 (Palindrome Theorem for Sublattice Cascades):** Let N ≥ 2 be a positive integer and g ∈ (ℤ/Nℤ)× a unit (gcd(g, N) = 1). Define:

$$d_n = \frac{N}{\gcd\!\left((gn) \bmod N,\; N\right)} \quad \text{for } n = 1, 2, \ldots, N$$

Then $d_n = d_{N-n}$ for all n = 1, ..., N−1.

### 7.2 Proof

**Step 1.** Let $r_n = (gn) \bmod N$. Then:

$$r_n + r_{N-n} = gn + g(N-n) = gN \equiv 0 \pmod{N}$$

Since gcd(g, N) = 1, neither $r_n$ nor $r_{N-n}$ equals zero for $0 < n < N$. Both lie in {1, ..., N−1}, so:

$$r_{N-n} = N - r_n \quad \text{(exact equality, not merely congruence)}$$

**Step 2.** Apply the Complementary GCD Lemma (D.2, proved separately in §8):

$$\gcd(r_{N-n}, N) = \gcd(N - r_n, N) = \gcd(r_n, N)$$

**Step 3.** Therefore:

$$d_{N-n} = \frac{N}{\gcd(r_{N-n}, N)} = \frac{N}{\gcd(r_n, N)} = d_n \qquad \blacksquare$$

### 7.3 Physical Significance

The palindromic symmetry is a **structural inevitability** of unit-generated orbits on ℤ/Nℤ. The proof uses only the complementary GCD identity — it does not depend on the specific value of g, the specific value of N, or any special numerical property of the configuration. Every unit generator on any modulus produces a palindromic d-sequence.

## 8. The Complementary GCD Lemma and Complementary Residue Theorem

### 8.1 The Complementary GCD Lemma (D.2)

**Lemma D.2:** For all r ∈ {1, ..., N−1}:

$$\gcd(r, N) = \gcd(N - r, N)$$

**Proof:** Let d = gcd(r, N). Then d | r and d | N, so d | (N − r), hence d | gcd(N−r, N). Symmetrically, gcd(N−r, N) | gcd(r, N). Therefore they are equal. ∎

**This lemma is the algebraic core of the palindrome theorem.** The palindrome does not require any self-inverse property of g; it requires only this elementary divisibility identity.

### 8.2 The Complement Map as Lattice Automorphism

Define $\sigma: \mathbb{Z}/N\mathbb{Z} \to \mathbb{Z}/N\mathbb{Z}$ by $\sigma(r) = N - r \equiv -r \pmod{N}$.

This map:
1. Is an involution: σ(σ(r)) = r
2. Fixes r = 0 (identity) and r = N/2 (tritone, for even N)
3. **Preserves the sublattice family:** d(σ(r)) = d(r) by Lemma D.2
4. Is an automorphism of the sublattice structure

The palindrome arises because the cascade traversal n ↦ r_n and its complement n ↦ r_{N−n} are related by this structure-preserving involution. The lattice involution σ is the algebraic encoding of the physical involution that maps ascending intervals to descending ones.

### 8.3 Remarks

- **Remark 1 (Scope):** Theorem D.3 applies for any N ≥ 2 and any unit g. It is elementary group theory, not a numerical coincidence.
- **Remark 2 (Non-units fail):** If gcd(g, N) > 1, the cascade is confined to a proper subgroup and the full-period palindrome does not hold. Partial palindromes hold over the reduced orbit (see §41).
- **Remark 3 (Universal pivot for even N):** For even N, every unit g is odd. Therefore $g(N/2) = (\text{odd})(N/2) \equiv N/2 \pmod{N}$. The midpoint always maps to residue N/2, giving $d_{N/2} = 2$ universally.
