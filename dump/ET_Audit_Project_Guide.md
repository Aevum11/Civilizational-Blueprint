## 3. Classification Criteria

**FUNDAMENTAL REQUIREMENT:** Both Identities and Sub-Identities must be **literal algebraic identities** — actual equations (A = B), inequalities (A ≤ B), set equalities (S₁ = S₂), or provable algebraic statements. If a card does NOT contain a provable algebraic statement, it is a Reference Card regardless of its content. One of the core purposes of this audit is to ensure that every card classified as an Identity or Sub-Identity IS a true algebraic identity.

### Identity Card (IC — Non-Trivial)
A **literal algebraic identity** (provable equation, inequality, or set equality) that establishes a substantive structural result in the framework. **Triviality is determined by what the identity DOES — its functional role — NOT by whether the algebra is simple or complex.** An identity is non-trivial if its function is structurally important, regardless of how elementary the underlying mathematics might be. But it MUST be an algebraic identity — a provable mathematical statement with an equation.

### Sub-Identity Card (SIC — Trivial)
A **literal algebraic identity** (provable equation, inequality, or set equality) that is functionally subordinate — a minor supporting step, a verification of a parent identity at a specific point, or a definitional intermediary that does not stand alone as a meaningful structural contribution. Serves as scaffolding for other identities. Again, this is about what it DOES, not algebraic complexity. But it MUST still be an algebraic identity — a provable mathematical statement.

### Reference Card (RC)
**NOT an algebraic identity.** Tables of computed values, metadata, definitions, organizational content, verification summaries, parameter listings, structural maps, naming conventions, or any card that presents information WITHOUT stating a provable algebraic equation. If a card computes specific values from a general identity (e.g., plugging N=12 into a formula and listing results), it is a Reference Card — the general identity is the algebraic statement; the specific computation is informational data.

**The test:** Does this card state a provable algebraic equation (A = B, A ≤ B, S₁ = S₂)? If YES → Identity or Sub-Identity (based on functional role). If NO → Reference Card.
