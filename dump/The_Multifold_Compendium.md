# PART III — SUBLATTICE FAMILIES

## 11. Definition and the Divisor Theorem

A **sublattice family** is a static structural property of the lattice $\mathcal{L}_N$. It is defined by:

$$d(k) = \frac{N}{\gcd(|k|, N)}$$

For each lattice coordinate $k$, the value $d$ classifies it into one of finitely many equivalence classes. The set of attainable $d$ values is exactly the set of $N/g$ for $g$ a divisor of $N$, which is exactly the **set of divisors of $N$**:

$$\boxed{\{d : d \text{ is a sublattice family of } \mathcal{L}_N\} = \{d : d \mid N\}}$$

**The number of sublattice families of $\mathcal{L}_N$ is exactly $\tau(N)$**, the number of positive divisors of $N$. This is the **palindromic depth function**:

$$\Pi(N) = \tau(N) = |\{d : d \mid N\}|$$

For N = 12: divisors are {1, 2, 3, 4, 6, 12}, so $\tau(12) = 6$ sublattice families. For N = 24: {1, 2, 3, 4, 6, 8, 12, 24}, so $\tau(24) = 8$. For N = 60: $\tau(60) = 12$. For N = 2520: $\tau(2520) = 48$.

**Proof that sublattice families are exactly the divisors of N:**

The Subsumption Law forces this. A sublattice must be a closed sub-structure of $\mathcal{L}_N$ — closed in the sense that it forms a complete descriptor system within itself, with no remainder. The only closed sub-structures of $\mathcal{L}_N$ that close without leaving a descriptor gap are those indexed by divisors of $N$. Anything that is not a divisor would leave a remainder — and by the Descriptor Gap Principle, that remainder would itself have to be promoted to a descriptor, meaning the candidate was not actually a sublattice family but an incomplete slice. The set $\{d : d \mid N\}$ is the unique set that closes under the Subsumption Law. ∎

This is a **theorem**, not a convention. The sublattice families are not chosen — they are forced by the divisor structure of N and the requirement that they close without remainder.

## 16. The Stability Window Theorem

The cascade above is structurally complete (the generator is a unit) and *also* numerically stable (the rounding never shifts). The second condition is the **Stability Window**.

$$\delta = (\lambda - k_1) \times 100 \quad [\text{cents}]$$

At level $n$, the exact position is $n\lambda$. The rounding is unambiguous if and only if $|n \delta / 100| < 0.5$, i.e. $|n\delta| < 50¢$. The maximum is at $n = N$, giving:

$$\boxed{\text{Stability Window:} \quad N \times |\delta| < 50¢}$$

1. The generator $g = |\text{round}(N \log_2 r)| \bmod N$ is a unit of $\mathbb{Z}/N\mathbb{Z}$

For $N = 12$ and $r = 1/12$: $|\delta| = 1.955¢$, $12 \times 1.955 = 23.5¢ < 50¢$. ✓

For the same $N$ and $r = 2/3$ (the Koide ratio): $|\delta| = 1.955¢$, same window. ✓

## 17. The Palindrome Theorem

**Theorem (Palindrome Theorem, D.3).** Let $N \geq 2$ be a positive integer and $g \in (\mathbb{Z}/N\mathbb{Z})^\times$ a unit of the modular group ($\gcd(g, N) = 1$). Define:

$$d_n = \frac{N}{\gcd((gn) \bmod N, N)} \quad \text{for } n = 1, 2, \ldots, N$$

Then $d_n = d_{N-n}$ for all $n = 1, \ldots, N - 1$.

**Proof.** Let $r_n = (gn) \bmod N$. Then $r_n + r_{N-n} = gn + g(N - n) = gN \equiv 0 \pmod N$. Since $\gcd(g, N) = 1$, neither $r_n$ nor $r_{N-n}$ is zero for $0 < n < N$, so both lie in $\{1, \ldots, N-1\}$ and $r_{N-n} = N - r_n$ exactly.

By the Complementary GCD Lemma: $\gcd(r, N) = \gcd(N - r, N)$ for any $r$. (Both are common divisors of the same set.) Therefore:

$$\gcd(r_{N-n}, N) = \gcd(N - r_n, N) = \gcd(r_n, N)$$

And so:

$$d_{N-n} = \frac{N}{\gcd(r_{N-n}, N)} = \frac{N}{\gcd(r_n, N)} = d_n \qquad \blacksquare$$

For $N = 12$ and the d-sequence (12, 6, 4, 3, 12, 2, 12, 3, 4, 6, 12, 1), the palindrome pairs are:

| Pair | $d_n$ | $d_{12-n}$ | Equal? |

| n=1, n=11 | 12 | 12 | ✓ |
| n=2, n=10 | 6 | 6 | ✓ |
| n=3, n=9 | 4 | 4 | ✓ |
| n=4, n=8 | 3 | 3 | ✓ |
| n=5, n=7 | 12 | 12 | ✓ |
| **n=6 (pivot)** | **2** | (self) | ✓ |

**All six pairs verified.** The cascade is a perfect palindrome centered on the tritone pivot at n=6.

The palindrome theorem holds for *any* unit generator on *any* manifold. It is not a property of N=12 alone. What N=12 adds is the unit-generator condition + the stability window + the palindromic depth maximum, which together force N=12 to be the canonical manifold.
