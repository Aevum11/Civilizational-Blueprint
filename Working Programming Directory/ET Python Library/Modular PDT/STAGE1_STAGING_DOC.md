## Boundary Marker Reference

The three marker patterns that define clean split points:

```
// @ETPL:native-library <name>        ← native lib starts (before inner === block)
// @ETPL:native-library-end <name>    ← native lib ends

// @ETPL:trace-c-extension <mod>      ← C-extension trace starts
// @ETPL:trace-c-extension-end <mod>  ← C-extension trace ends

// @ETPL:trace-stdlib <file>  // module=<name>   ← stdlib trace starts
                                                  (ends at next @ETPL:trace-* line)
```

For stdlib traces, the end boundary is **implied** (there is no explicit end marker) — it ends at the line before the next `@ETPL:trace-*` or `@ETPL:trace-c-extension` marker.
